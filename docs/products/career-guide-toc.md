# 【企画】◯◯型のための 自己PR・職務経歴書ガイド

第2商品の目次案。価格 2,480円 / A4 52ページ前後を想定。

---

## 1. 何を売るのか

**買う人**：転職を考えているが「自分の強み」を言葉にできない社会人（メインペルソナ①）
**買う瞬間**：980円の診断ガイドを読んで「自分がわかった」あと、
　　　　　　「では応募書類に何と書けばいいのか」で詰まったとき
**約束すること**：診断結果を、**そのまま提出できる文章に変換する**

980円の商品が「自分を知る」なら、こちらは「**知った自分を使って受かる**」。
同じ読者が両方買う理由がここにある。

---

## 2. ページ数の考え方

### 結論：A4 52ページ前後（48〜56）

| 判断材料 | 内容 |
|---|---|
| 既存商品との比較 | 980円 / 26ページ ＝ 約38円/ページ |
| 同単価なら | 2,480円 → 65ページ |
| **推奨** | **52ページ ＝ 約48円/ページ** |

**65ページにしない理由。**
転職活動中は時間がない。60ページを超えると「あとで読む」になって積まれる。
実務ガイドは読了率がそのまま満足度になるので、**読み切れる厚さ**が優先。

**26ページのままにしない理由。**
価格が2.5倍なのに分量が同じだと、割高感が先に立つ。
分量2倍・実用性で差をつけるのが、いちばん説明がつく形。

### 価格の根拠はページ数で語らない

2,480円を正当化するのは厚さではなく、**そのまま使える成果物の数**。

- 自己PR文例 **5本**（タイプ別・職種別）
- 職務経歴書サンプル **2本**（そのまま差し替え可）
- 面接頻出 **20問** の回答骨子
- 言い換え語彙 **100語**
- 書き込み式シート **4種**

販売ページではこちらを前面に出す。

### 制作量を現実的にする設計

8タイプ分を全部書くと 52 × 8 ＝ 416ページ相当になり、現実的ではない。
**共通章とタイプ別章を分離する。**

| 区分 | ページ数 | 執筆量 |
|---|---|---|
| 【共通】全タイプで同一 | 32ページ | 32ページ分 |
| 【タイプ別】8種類 | 20ページ | 20 × 8 ＝ 160ページ分 |
| **合計** | **52ページ** | **192ページ分** |

416 → 192 に減る。目次はこの分離を前提に組んである。

### 第1部　才能を「職務経歴」に翻訳する（10ページ）

診断結果を、そのままでは書類に書けない。ここが最初の関門。

| | 内容 | 区分 |
|---|---|---|
| 1-1 | 「強みがない」のではなく、**語彙がない**だけ | 【共通】 |
| 1-2 | 経験の棚卸しシート（書き込み式） | 【共通】 |
| 1-3 | **◯◯型の強みを、職場の言葉に言い換える**（変換表 30語） | 【タイプ別】 |
| 1-4 | **短所を長所に読み替える** — 「飽きっぽい」→「興味の幅」／「疲れやすい」→「察知力」 | 【タイプ別】 |
| 1-5 | やってはいけない言い換え — 盛りすぎの境界線 | 【共通】 |

> **1-4 がこの商品の核。** サイトが記事で一貫してやってきた
> 「欠点を才能として読み替える」を、応募書類という出口に接続する章。

### 第3部　職務経歴書を仕上げる（10ページ）

| | 内容 | 区分 |
|---|---|---|
| 3-1 | 書類で落ちる3つの理由 | 【共通】 |
| 3-2 | 職務要約の書き方 — **◯◯型の切り口** | 【タイプ別】 |

### 第4部　面接で話す（12ページ）

| | 内容 | 区分 |
|---|---|---|
| 4-1 | 頻出20問と回答骨子 | 【共通】 |
| 4-2 | 「あなたの強みは？」— **◯◯型の答え方** | 【タイプ別】 |
| 4-3 | 「短所は？」の安全な答え方 | 【タイプ別】 |
| 4-4 | 転職理由の言い方 — ネガティブをネガティブのまま言わない | 【共通】 |
| 4-5 | 逆質問リスト — 聞くと評価が上がる質問／下がる質問 | 【共通】 |
| 4-6 | **◯◯型が面接で陥りやすい罠** | 【タイプ別】 |

> 4-6 が差別化点。内省型は考えすぎて沈黙する、対人型は話しすぎる、
> 論理型は正論で場を固くする——といった、**タイプ固有の失敗**を扱う。
> 一般的な面接本には絶対に載っていない切り口。

---

### 第5部　選ばれる側から、選ぶ側へ（6ページ）

| | 内容 | 区分 |
|---|---|---|

タイプ別が24ページだと執筆量は 34 + 24×8 ＝ 226ページ分。
初版は**タイプ別を20ページに削る**方向で調整する。

## 5. 未確定・要判断

  ただし転職領域は財布が開くので、2,480円で試す価値はある
